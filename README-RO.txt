G-Way – demonstrație PWA

CE ESTE:
O primă machetă web instalabilă pentru iPhone. Include interfață albă, branding G-Way,
categorii și căutare care deschide rezultatele YouTube în browser.

LIMITĂRI IMPORTANTE:
- Acesta este un prototip, nu o aplicație completă și nu este încă publicat pe internet.
- Căutarea este redirecționată către YouTube; nu folosește încă YouTube Data API.
- Nu include încă player integrat, autentificare, abonamente sau descărcări.
- Pentru integrare reală este necesară configurarea API-ului și respectarea politicilor YouTube.

PUBLICARE:
Fișierele trebuie găzduite la o adresă HTTPS pentru instalarea PWA pe iPhone.
După publicare, deschide adresa în Safari > Partajare > Adaugă la ecranul principal.
