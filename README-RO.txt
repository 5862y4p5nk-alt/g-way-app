G-WAY – versiune reparată pentru căutare și redare

1. Înlocuiește în GitHub fișierele vechi cu toate fișierele din acest pachet (în rădăcina repository-ului).
2. Apasă Commit changes.
3. Așteaptă publicarea GitHub Pages, apoi reîncarcă site-ul în Safari.
4. Dacă vezi versiunea veche, închide complet fila și redeschide linkul.

Căutarea folosește API-ul public Internet Archive. Redarea directă funcționează numai când materialul are un fișier audio/video compatibil accesibil. Nu toate rezultatele au fișiere redabile.
IMPORTANT: „public”/accesibil pe internet nu înseamnă automat domeniu public sau drept de descărcare. Respectă licența fiecărui material. Acest prototip nu descarcă automat materiale.
Pe iPhone, redarea în fundal depinde de iOS, browser și tipul fișierului; nu este garantată în toate situațiile.
